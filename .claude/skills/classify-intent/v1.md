# classify-intent v1

Classifies a user prompt against `.claude/intent-policy.yml` and returns a single
intent label. Called by the `UserPromptSubmit` hook on every message.

## Interface

**Input (stdin):** `{"prompt": "<raw user message>"}`

**Output (stdout):** one label — `repo_evolution | business_operation | escape_hatch | unknown`

## Classification order

1. **Escape hatch** — if prompt contains any phrase from `escape_hatch.examples` → `escape_hatch` (no LLM call)
2. **Known slash command** — if prompt starts with `/cmd` and `cmd` is listed in a category's `commands:` → return that category (no LLM call)
3. **Unknown slash command or free-form** — call Haiku with a system prompt built from policy descriptions + examples; parse label from response
4. **Error / no API key / parse failure** → `unknown`

## Auth

Reads `ANTHROPIC_API_KEY` from environment. Falls back to `ANTHROPIC_API_DEPLOYMENT_KEY`
in `.env.services` (same helper pattern as `scripts/langfuse_cc_hook.py`).

## Policy file

`.claude/intent-policy.yml` — edit that file to add categories, commands, or examples.
This script needs no changes when the policy changes.

## Model

`claude-haiku-4-5-20251001`, `max_tokens=10` — response is a single label.
